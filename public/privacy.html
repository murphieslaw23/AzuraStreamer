Privacy Policy

Last updated: May 9, 2026

AzuraStreamer is a self-hosted application designed to bridge AzuraCast radio stations to live video platforms. Your privacy is important to us, and this policy outlines how your data is handled.

1. Data Collection and Storage

AzuraStreamer is designed to be self-hosted. Most data remains strictly within your own environment:

  • Configuration Data: API keys for AzuraCast, YouTube, and Twitch are stored locally in a SQLite database on your server.
  • Local Processing: Stream metadata (artist, title, cover art) is downloaded and processed locally to generate the live video feed.
  • Logs: Application logs are stored locally for diagnostic purposes and are not transmitted to any external servers.

2. Third-Party Services

By using AzuraStreamer to broadcast to external platforms, you interact with third-party APIs:

  • YouTube API Services: AzuraStreamer uses the YouTube Data API to create and manage live broadcasts. By using this tool, you are bound by the YouTube Terms of Service and the Google Privacy Policy.
  • Twitch API: Authentication and stream management for Twitch are handled via the Twitch API. Please refer to the Twitch Privacy Notice.

3. Data Usage

AzuraStreamer only uses your data to facilitate the live streaming process. We do not sell, share, or transmit your configuration data or API keys to any third party other than the respective platform APIs you choose to use.

4. Security

As a self-hosted tool, the security of your data largely depends on your server configuration. This instance does not enforce local authentication — secure your server and network appropriately.

5. Changes to This Policy

We may update this policy from time to time. Any changes will be reflected by updating the "Last updated" date at the top of this page.

6. Contact

Since this application is self-hosted, if you have questions regarding the data stored on your instance, please contact the administrator of your server.
